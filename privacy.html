Privacy Policy

Last updated: 7 November 2026

This site is a free, static Ziwei chart tool. There are no accounts, no registration, no payments, no ads, and no tracking or analytics. This page explains how your data is handled — the short answer is: everything stays on your own device.

1. What we collect

Nothing. This site has no server: it never receives, uploads or stores any of your data, and there is no third-party analytics or advertising tracking.

2. Birth data

The birth date, time, gender and birthplace you enter are used only inside your browser to compute the chart, and are never sent anywhere. The chart link keeps the birth details in the page address so the chart can be rebuilt locally; do not share the link if you do not want others to see them.

3. Stored on your device

The following are stored only on your device and can be cleared at any time: chart history (browser localStorage, up to 20 entries), downloaded interpretation year files and records (IndexedDB), and language and theme preferences. You can delete the year files from the interpretation panel with the delete-data button, or clear this site's data in your browser settings.

4. Year-file downloads

The thirteen-dimension interpretations need a data file per birth year (about 2 MB each). You can download it from GitHub Releases via the link in the panel, then pick the file to load it; the download is an ordinary file download and never sends your birth data anywhere. After downloading, the app verifies the file with SHA-256 before use.

5. Hosting and network

This site is hosted as static files on GitHub Pages, with no application server, no database and no account system. The app only loads this site's own static files, plus any year file you choose to download; it makes no other requests to any server.

6. Your rights

Because this site has no accounts and collects nothing from you, there is no server record to ask us to delete. The data on your device is entirely under your control and can be cleared at any time. If you have questions, please contact us through the GitHub project page.

7. Minors

The content on this site is for entertainment and study only. If you are under 18, please use it with a guardian's consent.

8. Changes to this policy

If this policy changes, the date above will be updated together with this page. As there are no accounts, we cannot notify you by email.
